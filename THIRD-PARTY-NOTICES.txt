Build/facade source: the occt-wasm revision above, including its OCCT submodule.
No changes to the embedded kernel are made by YO3MFS.

The embedded kernel can be replaced with a compatible uncompressed WASM module
using YO3MFS_STEP_KERNEL=/absolute/path/to/occt-wasm.wasm before launching.
The replacement is compiled safely as WebAssembly in the same sandbox; native
serialized machine code is never loaded. See docs/STEP.md in the repository
for source/rebuild instructions and compatibility limits. Reverse engineering
for debugging modifications to the LGPL library is not restricted by YO3MFS.
