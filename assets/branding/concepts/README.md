## Prompt

Create a polished brand design presentation for YO3MFS, a professional offline desktop 3MF model viewer for macOS, Windows and Linux. This is one cohesive logo and app-icon concept for user review, not a screenshot of an application. Wide landscape layout, warm off-white background, generous whitespace, precise editorial alignment. LEFT: a large crisp original vector-style geometric brand symbol followed by exact uppercase wordmark 'YO3MFS' (letters Y O, then numeral 3, then M F S), dark graphite geometric sans-serif, refined weight and spacing. The original symbol suggests an isometric 3D cube with a bold Y formed by three structural faces/edges, warm copper/peach accent #E8A98B and graphite #24282F. Keep the silhouette simple, distinctive, readable at 24px; no wireframe clutter, no printer or filament illustration, no Bambu logo. RIGHT: matching desktop app icon, large rounded square graphite tile with the same exact symbol centered in copper/peach, subtle bevel and restrained depth, high contrast and very clean silhouette, no wordmark inside the icon. BELOW: a small row showing the exact same icon at three successively smaller sizes and a flat monochrome version of the brand symbol. Add only small quiet section captions 'LOGO', 'APP ICON', 'SMALL SIZES'. Top small heading 'YO3MFS / IDENTITY CONCEPT'. No other copy. No decorative scene, no mockup devices, no glow, no busy gradients, no watermark. Aim for premium desktop developer/design tooling identity; optical balance and impeccable typography.
