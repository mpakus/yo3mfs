# YO3MFS v1.5.0

This release combines the previously unpublished STL/STEP preview with OBJ, PLY, and glTF/GLB support. Packages are published by the version-tag workflow only after all four native build jobs and required macOS signing/notarization checks pass. Current verification and remaining platform checks are recorded in [VALIDATION.md](../VALIDATION.md).

## Added

- OBJ polygon meshes, ASCII/little-endian/big-endian PLY, and self-contained glTF 2.0/GLB static scenes through all opening paths.
- Embedded vertex/base colors, glTF shared instances and nested placements, and polygon triangulation with bounded inputs and localized notices.

- ASCII and binary STL through the file picker, drop handler, startup path, and headless inspector. Multiple ASCII solids preserve their positions; binary headers beginning with `solid` are recognized correctly.
- STEP/STP previews through a sandboxed Open CASCADE kernel. Embedded CAD surfaces are tessellated in millimeters and assembly placements are retained in one combined neutral mesh.
- Bounded STEP input/memory, running-conversion cancellation and deadline, imported-face coverage checks, and safe handling of geometry far from the origin.
- English/Russian format messages and persistent STL unit/attribute and STEP conversion notes.
- Synthetic geometry regression fixtures, numerical unit/placement checks, dependency notices, replacement-kernel instructions, and hardened macOS STEP runtime checks.

## Fixed

- Update the STEP sandbox runtime from Wasmtime 48.0.6 to 48.0.8, including the ARM64 compiler and runtime security fixes. The embedded OCCT kernel remains pinned and unchanged.

## Compatibility

OBJ/PLY use millimeters with a notice; glTF meters and Y-up coordinates are converted to the viewer frame. External resources are never opened. Textures, PBR effects, transparency, animation, skins, morphs, and point clouds are outside the new static preview profile. See [OBJ/PLY/glTF support and limits](../MESH-FORMATS.md).

STL has no units; coordinates are interpreted as millimeters. Nonstandard colors/attributes are ignored with a notice. Degenerate STL facets are counted and skipped; invalid/truncated/nonfinite/over-budget input is rejected.

STEP is a tessellated preview of classic uncompressed Part 21 exchanges. Colors, names, PMI, external component files, and editable CAD topology are not loaded. OCCT may normalize/heal topology or omit unsupported entities; full root-transfer completeness cannot be verified. These limitations remain visible in Import notes. The first STEP load initializes the CAD engine; conversion then has a 60-second limit. See the [STEP profile](../STEP.md).

3MF geometry, Bambu project colors/painting, camera controls, backgrounds, and saved language/material settings remain available. Loading failure or cancellation retains the last successful scene. No model is rewritten or uploaded; slicing, editing, printing, and export remain outside the viewer.

## Packages

The release workflow retains separate macOS ARM64, macOS Intel, Windows x64, and Linux x64 packages plus combined SHA256SUMS. New tagged macOS builds require Developer ID signing, notarization, Gatekeeper checks, and the specific Wasmtime executable-memory entitlement. Local development builds are ad-hoc signed; a successful local build does not establish public signing or native acceptance elsewhere.

Packages include the STEP dependency notices and licenses. The Open CASCADE kernel retains its LGPL terms and supports a compatible replacement. Application-license selection, complete distribution compliance, broader exporter compatibility, and clean-system/native GUI acceptance remain separate release checks.
