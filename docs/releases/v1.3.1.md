# YO3MFS v1.3.1

## Added

- Downloadable packages on GitHub Releases for macOS Apple Silicon, macOS Intel, Windows x64, and Linux x64.
- Direct platform download links in the README and a combined `SHA256SUMS` file.
- Version-tag publishing after all four native builds, tests, and package checks pass.

## Changed

- Application and package version updated to 1.3.1. Bambu Studio project colors, painted faces, camera controls, and English/Russian UI remain available.

## Installation

- macOS: choose the DMG for your Mac, open it, and copy `yo3mfs.app` to Applications.
- Windows: extract the ZIP and run `yo3mfs.exe`.
- Linux: extract the tar.gz and run `./yo3mfs` in a graphical session. Built on Ubuntu 24.04; system graphics libraries and desktop portals are required.
- `SHA256SUMS` covers all four downloads. Verify the entry for your chosen package.

### macOS first launch

This release is not notarized. If macOS reports that Apple could not verify YO3MFS is free of malware, and you trust the build downloaded from this release:

1. Copy the app into Applications and try opening it.
2. Click **Done** in the warning.
3. Open **System Settings → Privacy & Security → Open Anyway** for YO3MFS.
4. Confirm **Open** and authenticate if requested.

macOS remembers this app-specific exception. See [Apple's instructions](https://support.apple.com/en-us/102445). A future Developer ID-signed and Apple-notarized build is needed to remove this verification warning for other users.

macOS packages use ad-hoc signatures and are not notarized. Windows packages are not Authenticode-signed. Native CI checks do not replace manual GPU, file-picker, drag-and-drop, or clean-system acceptance on every platform. No project license has been selected.
